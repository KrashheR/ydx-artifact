# Хендофф для Codex — перевёрстка мобильного меню под landscape-макет

Источник истины (визуал): `Ревизия Landscape v2.dc.html` — 5 экранов в альбомной ориентации **896 × 414** (логические px). Ниже — спека, чтобы переверстать реальный экран/UI приложения под эти макеты. Ориентация — landscape для ВСЕХ экранов (осознанный выбор: играть удобнее горизонтально). Не тяни в портрет.

## Дизайн-токены

**Цвета**
- Фон экрана: `#0F1512` (осн.), `#0c100e` (глубокий), холст ревью `#0b0f0d`
- Панели/карточки: `#1b211d`, `#161c19`; активная карточка `#242f27`
- Рейлы/полупрозрачные плашки: `rgba(21,27,24,.4–.6)`
- Золото (primary/CTA): `#d8af63` → градиент `linear-gradient(180deg,#d8af63,#b3812f)`; тёмный текст на золоте `#1a130a`
- Золото-акценты: `#B88A45` (надзаголовки), `#e7c074` (яркое), звёзды `#e7c074`
- Текст: заголовки/осн. `#D5C39A`, приглушённый `#879087`
- Зелёный (успех/прогресс): `#6fc69e`, `#9bd9bb`, `#2F6A57`
- Бордеры: `rgba(213,195,154,.1–.16)`; золотой бордер `rgba(184,138,69,.32–.5)`

**Шрифты**
- `Cormorant Garamond` (serif) — крупные заголовки экранов и названия уровней
- `Manrope` — весь UI, надзаголовки (letter-spacing .16–.22em, uppercase, 700)
- `JetBrains Mono` — таймеры, счётчики, коды (REF-xxxx), номера уровней

**Форма**: окно экрана radius 34; карточки 14–20; кнопки 10–14; хит-таргеты ≥ 44px; главный CTA в нижней зоне пальца.

## Экран 1 — Игровой экран (главный фикс)
Кадры сцен **16:10**, поэтому два кадра рядом НЕ делаем (получается квадратный кроп, детали теряются). Решение: **один целый кадр 16:10 + жест «до/после»**.
- Раскладка: `[левый рейл 150] [центр — кадр] [правый рейл 150]`, рейлы фон `rgba(21,27,24,.4)` с бордером-разделителем.
- **Левый рейл**: кнопка «назад» (40×40) сверху; надзаголовок `БЕЛЫЙ · 3/13` + название `Маяк Белой Чайки` (Cormorant 16); снизу (margin-top:auto) чип таймера `04:56` и чип счёта `2 / 5 ОТЛИЧИЙ`.
- **Центр**: кадр 16:10 (в макете 560×322) со слайдером сравнения. База — снимок B; поверх — снимок A, обрезанный `clip-path: inset(0 {100-c}% 0 0)`; вертикальный разделитель на `left:{c}%` с круглой ручкой (34px, иконка ‹›). Метки найденных отличий — золотые кольца 40px. Под кадром — `<input type=range>` (accent `#d8af63`), значение 0–100 = позиция разделителя.
- **Правый рейл**: настройки (40×40) сверху-справа; по центру — круглый FAB подсказки (64px, золото, счётчик «1») + подпись `ПОДСКАЗКА`.
- Механика «Перевернуть» из старого билда убирается полностью — её заменяет слайдер.

## Экран 2 — Меню экспедиций
- Раскладка: `[левая колонка 388] [карточка справа]`.
- Левая: бренд (значок-компас + `ТАЙНЫ ЭКСПЕДИЦИЙ`, один раз, без дубля), крупный заголовок `Выберите экспедицию` (Cormorant 42, 2 строки), подпись «Три маршрута. Один архив.»; снизу — точки пагинации (актив = растянутая) + пара круглых стрелок ‹ › рядом.
- Карточка: **вписана в высоту 414 целиком** (обложка ~150px, затем название `Белый меридиан`, полоса прогресса `9 / 13` (зелёная), строка «Последний уровень: …» с отступом снизу 12px, и золотой CTA «Продолжить экспедицию» прижат к низу). CTA не должен обрезаться и текст не наезжает на кнопку.
- Убрать: декоративный ряд из 13 точек (заменён одной полосой), непонятный счётчик «39/39», дубль лейбла.

## Экран 3 — Карта кампании
- Хедер (66px): назад · `ЭКСПЕДИЦИЯ / Белый меридиан` · справа полоса прогресса + `9/13` + настройки.
- Горизонтальный ряд карточек уровней (210px каждая): обложка 120px с номером `01` и статус-значком (✓ пройдено / бейдж «СЛЕДУЮЩИЙ»); тело — надзаголовок статуса, название в **фикс. высоте 2 строки с обрезкой** (чтобы «Ледовая платформа» не ломалась), футер в одну строку: звёзды слева + «Повторить» справа; у активного уровня вместо футера — полноширинная кнопка «Продолжить».
- Скролл читаем: приглушённая (opacity .5) карточка-«подсказка» на краю + полоса-скроллбар снизу.

## Экран 4 — Результат уровня
- Раскладка по центру: `[левая колонка 340] [правая колонка]`, вертикально отцентрованы (без пустот).
- Левая: круглая печать-галочка (зелёная), `УРОВЕНЬ 3 ПРОЙДЕН`, заголовок `Все отличия найдены` (Cormorant 42), подпись.
- Правая: 3 стата (Время `00:09` / Найдено `5/5` / Оценка ★★★); полоса кампании — **залито ровно 3 из 13**, 3-й сегмент подсвечен (НЕ 13/13 — это была ошибка старого макета); золотой CTA «Уровень 4 · …» + вторичные «Повторить» / «К выбору уровней».

## Экран 5 — Настройки
- Не модалка-на-один-тумблер, а полноценный экран: `[левый рейл 250] [контент]`.
- Рейл: `ЭКСПЕДИЦИОННОЕ СНАРЯЖЕНИЕ / Настройки`; навигация разделов (Язык актив · Звук · Игра · О приложении) с иконками; «Готово» (золото) прижато к низу рейла. Случайную иконку «солнце» из старого макета убрать.
- Контент: `ЯЗЫК ИНТЕРФЕЙСА` (RU актив / EN, две плашки); `ЗВУК` (слайдеры Музыка/Эффекты); `ИГРА` (тумблеры Подсказки/Вибрация).

## Правила адаптации
1. Все экраны — landscape, дизайн-ширина 896×414; масштабировать по короткой стороне, учитывать safe-area (чёлка/home-indicator).
2. Хит-таргеты ≥ 44px; главные CTA — в нижней/боковой зоне большого пальца.
3. Плотность: не оставлять пустых половин экрана (см. старые Настройки) и не обрезать контент по краю (см. старую карточку меню).
4. Числа — JetBrains Mono; заголовки — Cormorant; UI/капс-лейблы — Manrope.
5. Прогресс кампании всегда отражает реальный номер уровня (X из 13), не «всё залито».
