# Handoff: Архивный хаб (главное меню)

## Overview
Главное меню игры «Тайны экспедиций». После первого уровня хаб открывается на постоянную ротацию — сюда игрок возвращается между сессиями. Экран объединяет: продолжение кампании, ежедневный архив (daily reward), полевой архив (коллекция находок) и второстепенные кампании.

## About the design files
Файлы в этом пакете — **HTML-референсы**, сделанные как прототип внешнего вида и поведения, а не production-код для копирования. Задача — воссоздать эти макеты в вашем стеке (React/Vue/Unity UI/и т.д.), используя принятые в проекте паттерны и компоненты.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и состояния — финальные. Верстайте пиксель-в-пиксель, где это возможно в вашей среде.

## Ключевая идея макета: коллекция находок = архивное дело, не витрина товаров
Коллекция ("Полевой архив") сознательно НЕ сделана как магазин карточек. Визуальный язык — канцелярская папка дела:
- Каждая карточка находки — «файл»/бирка с вырезом-скобкой сверху (border-radius асимметричный: `3px 12px 12px 12px`, плюс маленький «ярлычок» с скрепкой-иконкой и надписью в верхнем левом углу — как ярлык папки).
- Внесённые находки: тёмно-коричневый «сургучный» кружок-печать в углу карточки (radial-gradient `#c96a44 → #832f18`) + маленький зелёный штамп-полоска «ВНЕСЕНО» под иконкой (никаких геймификационных бейджей типа «NEW»/скидок).
- Ещё не найденные — «запечатанные»: приглушённый паттерн (`repeating-linear-gradient` diagonal hatch, как крафтовая бумага), пунктирная рамка, знак вопроса вместо превью.
- Счётчик прогресса — не «X товаров», а «Внесено находок: 4 / 12» с моноширинным числом, как инвентарная опись.
- Кнопка — «Открыть архив находок», не «Открыть коллекцию» / не «Открыть магазин».
Эта метафора должна быть перенесена 1:1 в реализацию — она несёт сюжетную функцию, не декоративную.

## Screens / Views (на холсте, все состояния)
1. **Desktop · Хаб · середина кампании** (1440×900) — основной happy path: продолжение экспедиции, архив дня доступен (реварда еще не забраны), полевой архив на 4/12.
2. **Desktop · Хаб · архив дня собран** (1440×900) — вариант после получения ежедневной награды (иконка/статус меняются на «собрано»).
3. **Мобильный landscape** — тот же хаб в горизонтальной ориентации, сжатая топбар-плашка.
4. **Состояния карточек архива дня** (2 состояния: доступно / собрано) — компонентные состояния для реализации как отдельный переиспользуемый блок.
5. **Мини дизайн-система** — бейджи и статусы, кнопки (primary/secondary/disabled), токены цвета и типографики — см. нижнюю часть холста.
6. **Модалка «Награда дня»** — оверлей поверх хаба при получении ежедневной находки.

### Компоненты и параметры
- **Топбар**: высота 70px, лого-компас слева (SVG, `#B88A45`), справа — статус сохранения (зелёная точка `#6fc69e` + pulse), счётчик подсказок (лампочка-иконка + число, см. ниже), круглая кнопка настроек 38×38.
- **Счётчик подсказок** (переименован из «луп»/magnifying glass — это **хинт-валюта**, не поиск): иконка лампочки (outline, stroke `#d8af63`), число в JetBrains Mono, подпись «подсказ.» рядом. Использована в топбаре, в карточке «Архив дня» (награда «+1 подсказка»), в модалке получения и в мини-дизайн-системе (бейдж «+1 ПОДСКАЗКА»).
- **Карточка «Архив дня»**: eyebrow с иконкой календаря, серийный бейдж «СЕРИЯ · N ДНЕЙ» (иконка огня), заголовок находки, строка награды с иконкой лампочки, primary-кнопка «Открыть».
- **Панель «Полевой архив»**: асимметричный border-radius `3px 12px 12px 12px`, ярлык-бирка сверху слева (папка + текст «АРХИВ»/«ПОЛЕВОЙ АРХИВ»), сетка 4 колонки с находками (внесённые: печать + штамп «ВНЕСЕНО»; незаполненные: hatch-паттерн + пунктир + «?»), CTA «Открыть архив находок».
- **Кнопки**: primary — `linear-gradient(180deg,#d8af63,#b3812f)`, текст `#1a130a`, radius 7px, тень `0 8px 18px rgba(184,138,69,.25)`. Secondary — прозрачный/полупрозрачный фон `rgba(213,195,154,.05)`, рамка `rgba(213,195,154,.2)`, текст `#D5C39A`. Disabled — пунктирная рамка, курсор not-allowed, текст `#5d655d`.
- **Бейджи/статусы**: «НОВОЕ» (сплошной `#B85C38`), «В ПРОЦЕССЕ» (изумруд, точка), «ЗАВЕРШЕНО» (изумруд, чекмарк), «ЗАКРЫТО» (нейтральный), «СЕРИЯ · N ДНЕЙ» (золото, огонь), «+1 ПОДСКАЗКА» (золото, лампочка), «СОХРАНЕНО» (нейтральный тёмный, зелёная точка).

## Interactions & Behavior
- «Продолжить экспедицию» — главный CTA, ведёт в карту кампании/уровень.
- «Открыть» на карточке архива дня — открывает модалку получения награды (см. ниже), доступна раз в день; после получения кнопка/состояние карточки меняются на «собрано» (см. состояние 2).
- «Открыть архив находок» — переход в полноэкранный вид коллекции (папка находок), с тем же архивным визуальным языком.
- Модалка «Награда дня»: полупрозрачный оверлей поверх хаба, круглая иконка-лампочка по центру, заголовок «+1 подсказка получена», текст о серии, кнопки «Забрать» (primary) и «Закрыть» (текстовая).
- Незаполненные ячейки коллекции интерактивны только как «замочек с ?» — при наведении можно показать тултип с условием открытия (не реализовано в макете явно, уточнить у дизайнера при необходимости).

## Design Tokens
- Фон приложения: `#0e120f`; панель карточки: `#151B18`; вложенные карточки: `#222A25`; ярлык архива: `#262e28`.
- Золото (акцент/CTA): `#d8af63` → `#b3812f` (градиент кнопок); латунь (заголовки/лейблы): `#B88A45`; пергамент (основной текст): `#D5C39A`; вторичный текст: `#879087`; приглушённый текст: `#5d655d`.
- Изумруд (успех/статус): `#6fc69e` / `#2F6A57`.
- Сургуч/печать: `radial-gradient(circle at 35% 30%, #c96a44, #832f18)`.
- Рамки: `rgba(213,195,154,.14–.2)` стандартная; `rgba(184,138,69,.35–.45)` акцентная (золото).
- Шрифты: **Cormorant Garamond** (заголовки, serif), **Manrope** (UI-текст), **JetBrains Mono** (числа/счётчики/лейблы состояний).
- Радиусы: карточки архива — асимметрия `3px 12px 12px 12px` (эффект «папки»); обычные панели — `10–12px`; кнопки `7px`; чипы/бейджи `5–7px`.
- Тени: панели `0 14px 32px rgba(0,0,0,.32)`; кнопки-primary `0 8px 18px rgba(184,138,69,.25)`; модалка `0 30px 70px rgba(0,0,0,.6)`.

## Assets
Иконки — инлайн SVG (stroke-based, без внешних файлов): компас-лого, лампочка (подсказки), календарь, огонь (серия), чек (завершено). При переносе в прод можно оставить как SVG-компоненты или заменить на иконки из вашей иконочной библиотеки, сохранив те же пропорции обводки (stroke-width 1.6–1.9).
