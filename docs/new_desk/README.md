# Ревизия UI · Тайны экспедиций · v3

Обновлённые макеты 4 экранов (десктоп, 1920×1080). Открыть в браузере:
`Ревизия экранов v3.dc.html` — все 4 экрана на одном холсте (V1–V4).

## Что внутри
- `Ревизия экранов v3.dc.html` — исходник (разметка + инлайн-стили).
- `support.js` — рантайм только для просмотра прототипа. В прод НЕ переносить: воссоздайте разметку в своём стеке (React/Vue/и т.д.).
- `assets/` — реальные кадры сцен (JPG), вставляются на место превью уровней/экспедиций и снимков игры.

## Экраны и внесённые исправления
**V1 · Карта уровней**
- Плюрализация: «1 уровень пройден» (было «1 уровней»).
- Закрытые уровни: grayscale + затемнение → сразу отличимы от доступных.
- Прогресс маршрута вверху: сегментированная шкала 13 + «01/13».
- Пройденный уровень: крупные звёзды (2/3) + кнопка «Повторить».
- Текущий: золотая рамка, бейдж «СЕЙЧАС», «дышащее» свечение, кнопка «Играть».

**V2 · Модалка подсказки**
- Тон «выгода»: eyebrow «БЕСПЛАТНАЯ ПОДСКАЗКА» (вместо «закончились»).
- Чип ценности «+1 подсказка на этот уровень».
- Второй выход «Обойтись без подсказки».
- Живой размытый фон сцены (не чёрный).

**V3 · Выбор экспедиции**
- Убран «00/13» у закрытых — только условие открытия.
- Закрытые карточки: grayscale + затемнение.
- Повышен контраст описаний.
- Обновлён степпер-нить.

**V4 · Геймплей**
- Один счётчик отличий (пипсы перенесены в верхний трекер, дубль снизу убран).
- «Точность 0%» → «СЕРИЯ ×2» (позитивное подкрепление).
- Таймер на набор времени (нейтральный), не обратный отсчёт.
- «Реклама → подсказка» → «Подсказка» (лампа + счётчик + значок ролика).
- Снимки крупнее.
