# 05 — Тиры разработки и трекер прогресса

Единственный источник правды о статусе меты. Каждый агент в конце сессии: проставляет чекбоксы своих задач и добавляет строку в журнал (внизу). Тиры проходятся по порядку; внутри тира порядок задач указан.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово · `[!]` заблокировано (причина в журнале).

- [ ] T2.5 `WallOverlay.tsx`: секции кампаний, качество рамок, переход в replay из слота
- [ ] T2.6 Полка артефактов в кабинете (переиспользовать данные CollectionScreen; старый экран остаётся до T4)

- [ ] T3.4 Интеграция: после уровней с артефактом — предложение связи в ритуале возврата; финал кампании — анимация полной доски
