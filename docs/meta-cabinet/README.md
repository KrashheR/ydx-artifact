# Мета «Кабинет архивариуса» — пакет документов

Дата: 2026-07-19. Родительские документы: `docs/GAME_DESIGN_REVIEW_2026-07.md` (ревью и обоснование), `docs/game_concept.json` (канонический концепт игры).

Этот пакет — полный план реализации новой меты «Кабинет архивариуса» силами агентов (Codex + Claude), от дизайна до liveops.

## Что такое «12/10»

10/10 — это работающая декоративная мета, поднимающая retention. 12/10 — когда мета становится **лицом игры** и её маркетингом:

1. Кабинет — первый экран, который видит вернувшийся игрок, и он **всегда** отличается от вчерашнего (новый снимок, штамп, сдвиг нити на доске).
2. Скриншот доски расследования с красной нитью — главный арт страницы игры на Яндексе; иконка и обложка продают «детективный архив», а не «найди отличия №1000».
3. Каждая сессия заканчивается «ритуалом»: возврат в кабинет → анимация нового элемента → взгляд на прогресс карты. Игрок закрывает вкладку на позитивном моменте владения, а не на interstitial.
4. Игроку есть что терять: стена, серия штампов, ранг. Отписаться «дорого».
5. Мета генерирует liveops сама: новое «дело» = новая секция стены + новая ветка доски, без изменения кода.

## Правила работы с пакетом

- `05_PROGRESSION_TIERS.md` — единственный источник правды о статусе. Каждый агент в конце сессии обновляет чекбоксы своего тира.
- Изменения дизайна систем фиксируются в `01_VISION_AND_SYSTEMS.md`, а не в чатах.
- Тиры проходятся строго по порядку; внутри тира задачи можно параллелить по правилам из `04_AGENT_PLAYBOOK.md`.
