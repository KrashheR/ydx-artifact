# 03 — Арт и контент-пайплайн меты

Все новые ассеты следуют визуальному канону `game_concept.json → visualDirection` (тёплая бумага, латунь, приглушённый teal/охра; запрещены неон, глянцевые сундуки, candy-UI) и требованиям манифеста: каждая единица — запись в `ASSET_MANIFEST.md` + `ASSET_PROVENANCE.json`.

## 1. Список ассетов

### Кабинет (T2)

| Ассет | Формат | Примечание |
|---|---|---|
| Интерьер кабинета (база) | WebP 1600x1000 | Одна сцена, зоны под слоты; генерация через существующий levelgen-пайплайн (`scripts/levelgen`, image API) с ручным отбором |
| Интерьер: варианты апгрейдов | WebP-слои/спрайты | Лампа, окно×3 (по меридианам), кресло, глобус — отдельные накладываемые слои, не новые интерьеры |
| Рамки отпечатков (3 качества) | SVG/WebP | Скрепка / паспарту / латунная рамка; универсальные, снимок = существующее превью сцены |
| Печать дела (3 кампании) | SVG | Стилизованные архивные печати в палитре кампании |

### Доска (T3)

Фон пробковой доски (WebP), карточки улик (рамка-шаблон + существующие арты артефактов/превью), кнопка-булавка, текстура нити (SVG stroke с лёгкой неровностью).

### Альбом и карта (T3–T4)

Разворот альбома (WebP), штампы: daily (шаблон с датой), недельный особый, печати 7/14/30 (SVG). Карта меридианов: подложка (генерация в стиле map-handoff `sand-meridian`), фрагменты — маски поверх подложки.

### Лаборатория (T5)

Новых артов почти нет: фильтры/flip поверх существующих сцен; нужен только UI-шильдик модификатора и иконка «фотобумаги».

## 2. Правила генерации (levelgen)

- Интерьер и карту генерируем тем же пайплайном, что сцены (`levelgen:scene`), с промптами в каноне «premium semi-realistic illustrated archival photography», без читаемого текста и лиц.
- Слои апгрейдов: генерировать интерьер с апгрейдом и без, вырезать разницу маской (пайплайн масок уже есть в levelgen) — гарантирует пиксельное совпадение слоя с базой.
- Все финальные ассеты через `pnpm assets:optimize` перед коммитом.

## 3. Daily-модификаторы (контент-правила)

Детерминированная функция от локальной даты (расширение `dailyArchive.ts`):

- **Пул:** будни — случайная (seed=дата) сцена из пройденных кампаний игрока; если пройдено <5 уровней — архивные сцены 1–7 как сейчас. Сб/Вс — «особые дела» из архивных 7.
- **Модификаторы (будни, ротация):** `soft-timer` (мягкий таймер, из концепта `daily.softTimer`), `no-hints` (кнопка подсказки скрыта), `mirror` (зеркальная печать — T5, до этого не выпадает).
- Правило честности: модификатор не меняет хитбоксы кроме `mirror` (математическое зеркалирование); никаких «уменьшенных» хитбоксов — это главный источник ненависти игроков в жанре (см. ревью).

## 4. Тексты

- Все новые строки — `src/i18n/ru/common.json` + `en/common.json`, неймспейс `cabinet.*`, `board.*`, `album.*`, `rank.*`, `lab.*`.
- Выводы связей на доске переиспользуют тексты `postVictoryNote`/`levelStory` — новые тексты нужны только для 15 «выводов-связок» (по 5 на кампанию) и названий рангов.
- Названия рангов должны выдерживать EN-длину (напр. «Смотритель меридианов» / "Meridian Warden").
- ВАЖНО: кириллица в файлах — только UTF-8; известна порча cp1251 в `docs/plot` при работе некоторых агентов (см. `04_AGENT_PLAYBOOK.md`).

## 5. Чеклист приёмки ассета

1. Палитра соответствует `visualDirection.palette` (допуск — тёплые вариации).
2. Нет текста внутри изображения, нет лиц крупным планом, нет логотипов.
3. WebP, оптимизирован, размер файла ≤ существующих сцен-аналогов.
4. Запись в `ASSET_MANIFEST.md` + `ASSET_PROVENANCE.json` (источник: levelgen prompt id или ручной).
5. Проверен на 360x640 и 1280x720 (читаемость слотов, touch ≥44px).
